This entry is a single 1024×1024 PNG that condenses Wednesday 18 November 2026 into one picture. The TypeScript program beside it is deliberately tiny: it locates the bundled `entry.png` relative to its own module, copies those bytes into a writable output folder, then re-reads the result and refuses to report success unless the file starts with the eight-byte PNG signature. It uses only the Node 22 standard library, so the same bytes are produced on every offline run.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
